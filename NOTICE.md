# Notice

UTSR-ToolMeta is a normalized metadata dataset for LLM-Agent tool declarations. It is derived from public or research-oriented sources such as MCP tool catalogs, OpenAPI operation descriptions, framework tool integrations, tool-use benchmarks, and function-calling datasets.

This repository does not include:

- tool backend implementation code;
- private credentials;
- private user data;
- executable access to third-party services.

Tool names, descriptions, schemas, URLs, licenses, and source identifiers are retained or normalized for research traceability. Upstream projects and data providers retain their respective rights.

If you believe a record should be removed or corrected, please open an issue with the record identifier and source information.
