# UTSR-ToolMeta v0.2

This public edition contains the main 7,593-record dataset and overlapping 4,408-record and 2,000-record subsets. Data are under `data/`; schemas are under `schema/`.

`VERSION.json` describes this package. `statistics.json` contains dataset-level distributions. `MANIFEST.sha256` binds file hashes and sizes and excludes itself.

The public edition retains source identities, tool semantics, identifiers, ordering, and ten-field functional profiles while omitting construction-only traces and internal review assets. Profiles are rule- and AI-assisted derived labels, not human gold. No per-record AI metadata is added. See the repository README, DATASHEET, and licensing notices before use.
